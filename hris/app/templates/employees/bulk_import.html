Template Guide

Use the Excel template to create many employees in one import.

  • Required columns: `first_name`, `last_name`, `date_hired`, `employment_status`.
  • `employee_code` is optional and will auto-generate if blank.
  • `department_code`, `position_name`, and `shift_name` must match existing HRIS values.
  • Use `YYYY-MM-DD` format for all date fields.
